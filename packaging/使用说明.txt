启动
1. 将此 ZIP 解压到一个有写入权限的文件夹。
2. 双击“启动.bat”或“BiliFavOrganizer.exe”。
3. 浏览器会自动打开本地页面。服务运行期间请保持黑色控制台窗口打开；关闭窗口即可停止服务。

本便携包已包含运行环境，无需另外安装 Python 或执行 pip。
首次启动后，浏览器打开 http://127.0.0.1:8080 。如浏览器未自动打开，请手动访问此地址。

数据位置
配置、Cookie、模型供应商和收藏数据保存在当前 Windows 用户的：
%LOCALAPPDATA%\BiliFavOrganizer\
删除或升级程序文件不会删除该目录中的个人数据。请勿分享该目录。

升级
下载新版本便携 ZIP 并解压到新的文件夹，然后启动新版本。原用户数据会继续使用。

注意
GitHub 页面自动生成的“Source code”压缩包是源代码，不是便携程序。
