# 侧栏（日志/终端）+ 主题图标 + 整目录数据包

## Report

## [S1] Problem

1. **侧栏**：默认应「锁定」；日志页签须随侧栏；标题行偏高；无「终端」页签；未选中/选中无高亮；终端需忠实转发命令行。  
2. **主题图标**仍不对，应与「显示」页三选项一致。  
3. **导出/导入**应为完整数据目录 zip；旧版未加密数据导入后须转换。

## [S2] Design

### 2.1 侧栏

结构（左→右）：

```text
[侧栏内容区 320px] [窄条标签]
标签（自上而下）：日志 | 终端
```

| 规则 | 行为 |
|------|------|
| 默认 | **锁定**（`sidebar-pinned`），锁定按钮高亮变色 |
| 标签跟随 | 页签吸附在侧栏右缘（与内容同高起点）；**未钉住时也跟随**（不单独漂浮） |
| 标题栏 | 行高压缩（padding 约 4–6px） |
| 切换 | 点「日志/终端」切换内容；标题文字改为「运行日志 / 终端」 |
| 钉子 | 始终可见，**不随内容变**；钉住=固定；未钉=鼠标离开侧栏约 0.7s 后整栏（含标签）向左收起 |
| 终端 | **无清空按钮**；标题仅文字 + 钉子 |
| 选中高亮 | 当前页签底色/描边高亮 |
| 终端内容 | 服务端 stdout/stderr **按行转发**到前端（SSE 或轮询）；输入框可把命令交给服务端执行（`subprocess`，工作目录=项目/数据目录） |

### 2.2 主题图标

- 顶栏与「显示」页三态一致：**Auto（半圆）/ 浅色（太阳）/ 深色（月亮）**  
- 顶栏只显示**当前**一枚；点击循环；设置里三枚按钮 + 当前 **active 按下态**  
- 图标与设置内文案/图形同源

### 2.3 数据整目录包

| 操作 | 行为 |
|------|------|
| 导出 | 将 `USER_DATA_DIR` 打成 **zip**（config、secrets、data/、vault 等；排除 runtime/） |
| 导入 | 解 zip → 覆盖/合并到 `USER_DATA_DIR`；若包内 `library.sqlite3` 为**明文旧库**，导入后走 **mid 匹配迁移加密**（与现逻辑一致） |
| 兼容 | 仍接受旧 JSON bundle（`store.import_all`） |

### 2.4 测试

- 导出 zip 可再导入；明文库导入后存在 `.enc` 或等价加密结果  
- 终端转发 API 至少冒烟（echo）  
- 全量 unittest 全绿  

## [S3] Out of Scope

- 完整 TTY/ANSI 终端仿真（仅纯文本转发 + 一行命令）  
- 多标签终端、远程 shell
