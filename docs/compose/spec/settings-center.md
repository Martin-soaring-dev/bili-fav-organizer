# 设置中心（修订：全屏面板 / 术语 / 迁移 / 显示与数据）

## Report

## [S1] Problem

1. 设置面板过窄（仅右侧条带），主页红框内连接/模型仍堆在主界面；入口文案「⚙ 设置」过长。  
2. **老用户明文库**在启用加密后可能丢数据；需在 mid 一致时**继承旧库并加密**。  
3. 「重置密码 / 金库」等译制腔用语不当；应使用**修改密码（输入两遍）**等常见表述。  
4. 高级区**未展示内置默认提示词**；应支持单项保存、单项恢复默认、一键全部默认。  
5. 需增加子菜单 **显示**。  
6. 需增加子菜单 **数据**（导入/导出/清除 + 数据目录路径 + 打开目录）。

## [S2] Design

### 2.1 布局

- 设置打开后覆盖 **除左侧日志窗外的全部操作区**（`panels` 全域），不再侧栏小条。  
- 主界面原「连接配置 / 模型配置」**整块迁入设置**，主区默认不再显示（红框内容仅存在于设置内）。  
- 顶栏按钮文案改为 **`[⚙]`**（tooltip「设置」）；保留 `[🔒]`。

### 2.2 术语（UI 禁用「金库」）

| 不用 | 使用 |
|------|------|
| 金库 | 本地加密 / 数据已加密 |
| 重置密码 | **修改密码** |
| 恢复码 | 恢复码（保留） |
| DEK/KEK | 不在 UI 出现 |

安全文案示例：「已设置应用密码 · 已解锁」「修改密码：当前密码 + 新密码 + 确认新密码」。

### 2.3 设置子菜单（左标签，分隔线）

```text
账号
模型
安全
显示          ← 新增
收藏
数据          ← 新增
高级
```

**显示**：界面主题（跟随系统/深色/浅色）、字号或日志密度（若有现成配置项则绑定，否则主题 + 预留项说明「暂不可用」）。

**数据**：

- 导入 / 导出 / 清除（迁入原顶栏三按钮逻辑）  
- 数据目录路径只读文本框 +「打开目录」按钮（后端返回 `USER_DATA_DIR`；前端 `POST /api/data/open-folder` 或系统 `os.startfile`）

### 2.4 修改密码（安全）

- 字段：当前密码（未解锁时）、新密码、确认新密码（两遍一致）  
- 文案「修改密码」，无「重置」  
- 解锁状态下可仅填新密码 + 确认；改密后 DEK 不变、收藏数据不丢

### 2.5 老用户数据迁移

启动/首次加密时：

1. 若存在**明文** `library.sqlite3` 且尚无 `library.sqlite3.enc`  
2. 且 `bound_mid` 为空或与 cookie 中 `DedeUserID` **一致**  
3. 则：生成 DEK → 用现有明文库 **整库加密** → 保留明文库为 `library.sqlite3.plain-backup`（或迁移成功后可选删除）  
4. mid **不一致** → 不迁移，提示「检测到其它账号的数据，未导入」

### 2.6 高级提示词

- **默认值**：打开时若用户未配置，文本框显示**内置默认全文**（从后端 `GET /api/prompts/defaults` 或 config 回读默认）  
- 每组：**单独「保存」** + **「恢复默认」**；底部 **「全部恢复默认」**  
- 保存写入 config；恢复默认删除用户覆盖、回填内置默认

### 2.7 测试

- 修改密码两遍不一致拒绝；改密后旧数据仍可读  
- 迁移：明文库 + mid 匹配 → 加密成功；mid 不匹配 → 不覆盖  
- 默认提示词 API 返回非空；单项保存/恢复  

## [S3] Out of Scope

- 云同步、多语言完整 i18n
