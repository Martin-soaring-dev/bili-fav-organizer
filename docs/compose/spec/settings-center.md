# 设置中心 + 锁定按钮 + 收藏夹同步修复

## Report

## [S1] Problem

1. **无法同步收藏夹**：界面报「刷新目录失败: Failed to fetch」（网络层失败，而非业务 JSON 错误），需查明并修复。  
2. **设置入口分散**：连接配置、模型管理、应用密码、数据导出等挤在主页/顶栏，弹窗堆叠，不像「设置」。  
3. **锁定交互不清**：`[🔒应用密码]` 与金库密码混用；需要独立 `[🔒]` 一键锁定，以及 GPT Desktop / Windows 设置式「⚙设置」侧栏。

## [S2] Design

### 2.1 信息架构

顶栏右侧：

| 控件 | 行为 |
|------|------|
| **`[⚙ 设置]`** | 打开**覆盖右侧**的设置面板（不居中小弹窗）；宽 ≥360px，左侧标签栏 + 右侧内容 |
| **`[🔒]`**（tooltip「锁定」） | 立即锁定金库（清 DEK、可选加密落盘）；解锁后**默认不自动再锁**，仅手动/重启/会话策略锁定 |
| 取消 | 原顶栏「🔒 应用密码」（功能并入设置） |

设置左侧标签（自上而下，分隔线）：

```text
账号
────────
模型
────────
安全
────────
收藏
────────
高级
```

### 2.2 设置面板内容

**账号**

- 账号信息：头像、mid、昵称、等级、经验、关注、粉丝、动态等**能获取到的**（接口不足则显示「暂不可用」）  
- 登录信息：与现「连接配置」登录区等价（扫码/手动 Cookie、测试 Cookie、状态）

**模型**

- 概览：当前活跃模型摘要（现主页模型配置块）  
- 模型管理：现「管理模型」弹窗内容（供应商/模型列表/测试/远程同步）

**安全**

- 密码管理：修改密码；**解锁状态下可直接重置**（新密码 + 重建 password Wrap，DEK 不变）  
- 验证方式：应用密码（必选）；Windows Hello（可选；**必须先有应用密码**才能绑定）

**收藏**

- 本地数据浏览：等价「查看本地内容」（收藏夹树、条目、详情、画像只读浏览）

**高级**

- 收藏夹画像：提示词、置信度阈值；**恢复默认**  
- LLM 归类分析：提示词、置信度阈值；**恢复默认**  
- AI 合并建议：提示词、置信度阈值；**恢复默认**  

配置落盘 `config.json`（如 `prompt_profile` / `prompt_analyze` / `prompt_merge` 与对应 `*_confidence_min`）；未配置用代码默认；「恢复默认」写回默认值或删除键。

### 2.3 交互与风格

- 参考 GPT Desktop / Windows 设置：左栏 140–160px 标签，右栏滚动内容；选中态高亮  
- 不破坏现有「快速模式 / 主流程」主区布局  
- 设置面板打开时主界面可只读或保持交互（不强制遮罩全屏）

### 2.4 锁定

- `POST /api/vault/lock`：保存加密库、清 DEK  
- UI `[🔒]` 调用之，并显示锁屏（现有解锁框）  
- 解锁后**不**自动锁定（默认保持解锁直到手动锁/重启）

### 2.5 收藏夹同步修复

- 复现「Failed to fetch」：检查 `POST /api/folders/refresh` 超时/崩溃/token/金库 403 是否被前端吞成网络错误  
- 修复：错误分类（业务 JSON vs 网络）；必要时给 fetch 超时与重试；确保金库已解锁时同步成功

### 2.6 测试

- 单测：vault reset-password 在解锁态可换密且 DEK 保留；folders/refresh 金库锁定时返回明确 `app_locked`；prompt 配置读写与恢复默认  
- 全量 unittest 全绿

## [S3] Out of Scope

- 真实 B 站用户信息完整爬取（仅用现有接口）  
- 多账户切换、云端设置同步
