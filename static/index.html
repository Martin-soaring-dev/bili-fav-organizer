业务
    手动模式：请按下方「获取收藏明细 → 收藏夹画像 → 内容整理 / 收藏夹整理」自行逐步操作。

    🔍 获取收藏明细

    先同步收藏夹目录；已建索引的内容优先本地复用，缺失元数据再按接口能力读取。小收藏夹使用 ID 清单核对，较大的夹使用分页明细。完整快照提交后会清理已取消收藏的夹内关系。

    未加载目录
    快速模式下，下方三栏仅供查看；切换到手动模式后可操作。

    🗂 合并组草稿

    根据收藏夹画像和代表内容生成候选合并组，然后在表格中编辑确认。所有有内容的 active 收藏夹都必须有当前完整画像。

    📋 已提交合并任务

    预览已提交的任务。如需调整，请修改上方草稿后重新提交。

    🧭 收藏夹画像生成 / 重建

    对本地已扫描的全部内容按上下文窗口分批压缩，再综合生成简介、主题、适合收纳范围和明显范围外内容。收藏夹名称只作弱提示；只有扫描完整的收藏夹可生成画像。默认收藏夹是未分拣收件箱，不生成画像。

    🤖 LLM 归类分析

    批量调用已配置模型，为每个视频推断应归属收藏夹。分类依据是收藏夹的当前画像；只有所有有内容的 active 收藏夹都已完成扫描并生成最新画像后才能分析。批大小是单批上限，发送前会按上下文预算自动拆分。

    📊 预归类方案

    默认显示归类统计；点「查看详情」逐条修改目标收藏夹，确认后进入执行。
